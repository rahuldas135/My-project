About the project

Learn by building

QuizMaster combines a responsive learning website with secure account handling and personal quiz history.

Technologies

TechnologyPurpose
HTML and CSSPages, forms, and responsive design
JavaScriptQuiz interactions, validation, and profile display
Node.js and ExpressBackend routes, authentication, and access control
MongoDB AtlasUser accounts, quiz results, and sessions
bcryptPassword hashing before storage

Account privacy

Each signed-in learner can view their own profile and quiz history. The admin dashboard requires the configured administrator account. It displays user and quiz activity but never password hashes.

Run locally

  1. Run npm install in the project folder.
  2. Copy .env.example to .env.
  3. Add your MongoDB Atlas URI, session secret, and admin email/password.
  4. Run npm start, then open http://localhost:8000.

Password reset email and email verification need an email service and are not configured here.
